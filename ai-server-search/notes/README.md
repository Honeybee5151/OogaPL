# Research notes for the feasibility verdict (2026-11-08)

Raw evidence behind `../feasibility.md`, written by research agents. Every claim has a label and a link; most have
an exact quote. Paths starting with `/tmp/...` refer to the research session's scratch folder, which no longer
exists. The links to primary sources are what matter.

| File | What it covers |
|---|---|
| `T1-ai-search.md` | AlphaEvolve, FunSearch, AlphaDev, Berkeley ADRS, open tools, failure modes (cheating the scorer, overfitting) |
| `T2-costs.md` | What makes MMO servers expensive; cloud vs Hetzner prices |
| `T3-network.md` | Interest management, update priorities, snapshot compression |
| `T4-compute.md` | World partitioning, load balancing, packing sessions onto servers |
| `T5-data.md` | Public traces, benchmarks and testbeds for building a scorer |
| `T6-novelty.md` | Has this been tried? Past efforts to scale MMOs cheaply, and why they stalled |
| `G1.md` | Gap research: open-source RuneScape private servers (rsprot, rsmod, 2004Scape) and their measured hot paths |
| `G2.md` | Gap research: real capacity numbers for RuneScape-style worlds |
| `G3.md` | Gap research: how well coding agents optimise code in 2026, cheating risks, plan vs API usage |
| `fact-checks.md` | Per topic: what the adversarial checker confirmed, corrected or refuted |
| `critic.md` | The completeness critic's gaps and framing problems |
| `judges.md` | The three independent judges' full verdicts, scores, candidates, stop rules and first experiments |

Where `fact-checks.md` corrects a claim in a topic file, the correction wins.
