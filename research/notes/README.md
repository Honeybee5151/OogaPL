scratch folder and no longer exist; the links to primary sources are what matter.

- `B-language-prior-art.md`: Pony, Roc, Halide, Verona, Koka, Zig, Odin, Bend and others.
- `C-runtimes-rust.md`: Seastar, Tokio, Bevy, flecs, GGPO/GGRS, floats, and the Rust crates that could act as a library version.
- `D-performance.md`: numbers for each pattern, with workload, baseline and source.
